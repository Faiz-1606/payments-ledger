Race demo

Four demo wallets. Press Run race and the server fires N transfers between them at the same time (16 threads), using the locking strategy you pick. Transfers only move money between these wallets, so their total must never change, and each wallet's stored balance must equal the sum of its ledger entries.

Why the ledger sum stays ₹0.00 even in naive mode: every transfer still writes its two ledger entries (−amount, +amount). What naive mode breaks is the stored balance (balance = old value − amount computed from a stale read, overwriting a concurrent update), so balances drift away from the ledger. That is exactly what the reconciliation job detects. API docs: Swagger UI.
